# Real / camera photos

Put images in this folder that you know came from a real camera or a real photo
workflow (phone, DSLR, scanned negative). 20+ files is a good start.

What helps:
- raw camera exports **and** the same photos after re-saving/WhatsApp/Instagram,
  because that is what users actually upload
- different phones, lighting and subjects
- a few screenshots of real photos too, if you want those handled well

What hurts:
- stock images that were already processed beyond recognition
- duplicates of the same photo (they inflate agreement without adding information)

Run the calibration with:

    cd backend
    .venv\Scripts\python.exe tools\calibrate.py
